## Дизайн система

### Цвета
```css
Фон основной: #FFFFFF (white)
Фон акцентный: #faf9f7 (бежевый)
Фон темный: #5c1a1a (темно-бордовый)
Текст основной: #000000 (черный)
Текст вторичный: #666666 (серый)
Акцент: #5c1a1a (темно-бордовый)
```

### Типографика

**Заголовки:**
- Font: Playfair Display
- Sizes: 3xl - 8xl
- Weight: 300-400
- Letter spacing: -0.02em to 0.01em

**Текст:**
- Font: Open Sans
- Weight: 300-400
- Letter spacing: 0.02em - 0.3em
- Line height: 1.6-1.8

### Эффекты и анимации

**Parallax:**
```javascript
transform: translateY(${scrollProgress * 50}px) 
          scale(${1 + scrollProgress * 0.1})
```

**Fade in up:**
```css
@keyframes fadeInUp {
  from: opacity 0, translateY(30px)
  to: opacity 1, translateY(0)
}
```

**Hover эффекты:**
- Scale: 1.05 - 1.125
- Duration: 300ms - 700ms
- Easing: cubic-bezier

**Scroll progress:**
- Отслеживание позиции скролла
- Анимация стрелки (fade out)
- Параллакс фона

## Responsive дизайн

### Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

### Адаптация
- **Hero:** Размер текста 5xl → 8xl
