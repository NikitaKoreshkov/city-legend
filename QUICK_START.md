# 🚀 Быстрый старт для новых страниц

## Что было создано

✅ **Страница О нас** - `/about` 🌟
- Полноэкранная hero секция с параллаксом
- Манифест компании с цитатами
- Достижения и цифры (4 метрики)
- Timeline истории (2018-2025)
- 4 ключевые ценности
- CTA секция
- Премиальный дизайн в стиле Haute Couture

✅ **Панель контактов в хедере** (иконка телефона)
- Телефон для звонка
- Кнопки WhatsApp и Telegram
- Email
- Адрес офиса
- Часы работы
- Красивое оформление в стиле Old Money

✅ **Страница Документы** - `/documents`
- Поиск в реальном времени
- Фильтр по периоду
- Сортировка (новые/старые)
- **Автоматическое скачивание** при клике на документ

✅ **База данных**
- Таблица `documents` для хранения документов
- Таблица `contact_submissions` для обращений

✅ **API Endpoints**
- `GET /api/documents` - получение документов с фильтрацией
- `POST /api/documents` - добавление документов (для админки)
- `POST /api/contact` - отправка формы обратной связи
- `GET /api/init-db` - инициализация БД

## Как запустить

### 1. Запустить сервер

```bash
npm run dev
```

### 2. Открыть страницы

- http://localhost:3000/about - **О нас** (WOW! 🌟)
- http://localhost:3000/documents - Документы
- Кликните на иконку телефона в хедере - откроется панель контактов

**Всё работает автоматически!** 🎉
- База данных создается автоматически
- Тестовые документы добавляются автоматически
- Скачивание работает сразу (2 тестовых PDF уже созданы)

### Для разработчиков

#### Добавить новый документ через код:

```javascript
await fetch('/api/documents', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'Название документа',
    file_url: '/path/to/file.pdf',
    file_size: '1.2 МБ',
    file_type: 'PDF',
    document_date: '2025-12-29'
  })
});
```

#### Просмотреть все обращения:

Обращения сохраняются в таблице `contact_submissions`. 
В будущем можно создать админ-панель для просмотра.
