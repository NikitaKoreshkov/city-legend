# Документация по страницам Контакты и Документы

## Обзор

Были созданы:

1. **Панель контактов в хедере** - через иконку телефона открывается красивая панель с полной контактной информацией
2. **Страница Документы** (`/documents`) - с поиском в реальном времени, фильтрацией, сортировкой и скачиванием документов

## База данных

### Таблица `documents`

```sql
CREATE TABLE documents (
  id SERIAL PRIMARY KEY,
  title VARCHAR(500) NOT NULL,
  file_url TEXT NOT NULL,
  file_size VARCHAR(50),
  file_type VARCHAR(10) DEFAULT 'PDF',
  document_date DATE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```


## Инициализация базы данных

### Вариант 1: Через API endpoint (рекомендуется при первом запуске)

1. Запустите сервер разработки:
```bash
npm run dev
```

2. Откройте в браузере:
```
http://localhost:3000/api/init-db
```

Это создаст все необходимые таблицы.

### Вариант 2: Автоматически при запуске

База данных инициализируется автоматически при первом обращении к API.

## Добавление тестовых документов

После инициализации БД добавьте тестовые документы:

```bash
npm run seed:documents
```

Это добавит 9 примеров документов с разными датами для демонстрации работы фильтров и сортировки.

## API Endpoints

### Документы

#### GET `/api/documents`
Получить список документов с фильтрацией и сортировкой

**Параметры запроса:**
- `search` (string) - поиск по названию
- `sort` (string) - `desc` (новые первые) или `asc` (старые первые)
- `startDate` (string) - начальная дата фильтра (YYYY-MM-DD)
- `endDate` (string) - конечная дата фильтра (YYYY-MM-DD)

**Пример:**
```
GET /api/documents?search=протокол&sort=desc&startDate=2025-12-01
```

**Ответ:**
```json
{
  "documents": [
    {
      "id": 1,
      "title": "Архив итоговых протоколов от 23.12.2025",
      "file_url": "/documents/archive-23-12-2025.pdf",
      "file_size": "530.87 КБ",
      "file_type": "RAR",
      "document_date": "2025-12-23",
      "created_at": "2025-12-29T10:00:00.000Z"
    }
  ],
  "count": 1
}
```

#### POST `/api/documents`
Добавить новый документ (для админ-панели)

**Тело запроса:**
```json
{
  "title": "Название документа",
  "file_url": "/documents/document.pdf",
  "file_size": "1.2 МБ",
  "file_type": "PDF",
  "document_date": "2025-12-29"
}
```

### `/documents` - Документы

**Функционал:**
- **Поиск в реальном времени** - результаты обновляются автоматически при вводе
- Фильтрация по диапазону дат
- Сортировка (новые/старые первые)
- Отображение информации: название, дата, тип файла, размер
- **Автоматическое скачивание** документов по клику
- Счетчик найденных документов
- Breadcrumb навигация
- Responsive дизайн

**Особенности:**
- Поиск с debounce 300мс (оптимизация запросов)
- Автоматическое обновление при изменении любых фильтров
- Кнопка "Очистить фильтры"
- Плавные анимации при наведении
- Иконка файла для каждого документа
- 2 тестовых PDF файла уже созданы
