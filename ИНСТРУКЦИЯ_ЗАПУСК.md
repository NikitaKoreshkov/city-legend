# 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ АДМИН ПАНЕЛИ

## Проблема: 401/500 ошибки при входе

Это происходит потому что база данных еще не инициализирована с новыми таблицами.

## ✅ РЕШЕНИЕ (2 способа):

### Способ 1: Перезапустить сервер (РЕКОМЕНДУЕТСЯ)

1. **Остановите сервер** (Ctrl+C в терминале где запущен `npm run dev`)

2. **Запустите снова:**
```bash
npm run dev
```

3. **Перейдите на страницу логина:**
```
http://localhost:3000/admin/login
```

4. **Войдите:**
- Логин: `1`
- Пароль: `1`

При первом входе автоматически создадутся все необходимые таблицы!

### Способ 2: Вручную инициализировать БД

Если перезапуск не помог, выполните в терминале:

```bash
# Перезапустите сервер
npm run dev

# В новом терминале выполните:
curl http://localhost:3000/api/init-db
```

Затем попробуйте войти снова.

## 📝 Что должно произойти:

После успешной инициализации будут созданы таблицы:
- `admin_users` - администраторы (логин/пароль: 1/1)
- `homepage_content` - контент главной страницы
- `about_content` - контент страницы О нас
- `auction_categories` - категории аукционов
- `auction_subcategories` - фильтры
- `contact_requests` - обратная связь

## ✨ После успешного входа:

Вы попадете на главную страницу админки с двумя разделами:
1. **Редактировать сайт** - управление контентом
2. **Обратная связь** - просмотр заявок

## 🆘 Если все равно не работает:

Проверьте переменную окружения `DATABASE_URL` в файле `.env.local`:
```
DATABASE_URL=postgresql://user:password@localhost:5432/database_name
```

Убедитесь что PostgreSQL запущен и доступен.
