# 📋 Дополнительные секции (аккордеоны) для лотов

## ✨ Что добавлено:

Теперь для каждого лота можно настроить дополнительные раскрывающиеся секции (аккордеоны), которые отображаются на странице лота под основным описанием.

## 🎯 Как использовать:

### В админ панели (`/admin/edit/auctions`):

1. **Откройте редактирование лота** (или создайте новый)
2. **Прокрутите вниз до секции "Дополнительные секции (аккордеоны)"**
3. **По умолчанию есть 3 секции:**
   - Детали продукта
   - Уход и обслуживание
   - Возврат и обмен

### Управление секциями:

#### ✅ Редактирование секции:
- **Заголовок** - название, которое видит пользователь (например: "Детали продукта")
- **Содержимое** - текст, который раскрывается при клике (можно использовать многострочный текст)

#### ➕ Добавление новой секции:
- Нажмите кнопку **"+ Добавить секцию"**
- Заполните заголовок и содержимое

#### ❌ Удаление секции:
- Нажмите кнопку **"Удалить"** рядом с нужной секцией

### 💾 Сохранение:
- Нажмите **"Сохранить"** внизу формы
- Все секции сохранятся вместе с лотом

## 🌐 На сайте:

После сохранения секции автоматически появятся на странице лота:
- Под описанием товара
- В виде раскрывающихся блоков (аккордеонов)
- С красивой анимацией при открытии/закрытии

## 📌 Важно:

1. **Секции индивидуальны** - у каждого лота свои секции
2. **Можно добавить сколько угодно** секций
3. **Если секции не настроены** - отображается дефолтная секция "Детали продукта"
4. **Текст поддерживает переносы строк** - используйте Enter для форматирования

## 🔄 Перезапуск сервера:

После обновления кода **перезапустите сервер**, чтобы новая колонка `detail_sections` добавилась в БД:

```bash
# Остановите сервер (Ctrl+C)
# Запустите снова:
npm run dev
```

При первом запросе к БД автоматически выполнится миграция и добавится новая колонка.

## 💡 Пример использования:

### Для картины:
- **Детали продукта:** "Холст, масло, 50x70 см, 1985 год"
- **Сертификат подлинности:** "Включен оригинальный сертификат от галереи"
- **Состояние:** "Отличное, без реставрации"

### Для часов:
- **Технические характеристики:** "Механизм: автоматический, Swiss Made..."
- **Комплектация:** "Оригинальная упаковка, гарантийный талон, документы"
- **Обслуживание:** "Последнее ТО: 2023 год"
