# Сертификат подлинности

## Описание

Премиальная функция для добавления сертификата подлинности к каждому лоту.

### Дизайн
- Элегантная ссылка "Сертификат подлинности →" под ценой товара
- Минималистичный hover-эффект с подчеркиванием
- Красивое модальное окно с плавной анимацией открытия
- Полноэкранный просмотр изображения сертификата

## Как добавить сертификат к аукциону

### Вариант 1: Через SQL (для тестирования)

```sql
UPDATE auctions 
SET certificate_url = '/path/to/certificate.jpg'
WHERE id = [ID_АУКЦИОНА];
```

### Вариант 2: Через API (для будущей админ-панели)

```typescript
await fetch(`/api/auctions/${auctionId}`, {
  method: 'PATCH',
  body: JSON.stringify({
    certificate_url: '/certificates/certificate-123.jpg'
  })
});
```

### Вариант 3: Загрузка файлов

1. Создайте папку `/public/certificates/`
2. Загрузите изображение сертификата (JPG, PNG)
3. Обновите поле `certificate_url` в БД с путем `/certificates/your-file.jpg`

## Формат файлов

- **Поддерживаемые форматы**: JPG, PNG, PDF (через изображение)
- **Рекомендуемое разрешение**: 1500x2000px или выше
- **Максимальный размер**: 5MB

## Пример структуры

```
public/
  certificates/
    painting-collection-1.jpg
    vintage-watch-789.jpg
    imperial-porcelain-456.png
```

## База данных

Поле `certificate_url` в таблице `auctions`:
- **Тип**: TEXT
- **Nullable**: YES
- **Описание**: URL или путь к файлу сертификата

## UI/UX

- Ссылка появляется только если `certificate_url` не пустой
- При клике открывается модальное окно
- Модальное окно закрывается при:
  - Клике на кнопку × (крестик)
  - Клике вне изображения
  - Нажатии ESC (можно добавить)
