# Быстрый старт - Админ Панель

## 🚀 Запуск

1. **Запустите сервер разработки:**
```bash
npm run dev
```

2. **Инициализируйте базу данных:**
Перейдите по адресу: `http://localhost:3000/api/init-db`

Это создаст все необходимые таблицы и учетную запись администратора.

3. **Войдите в админку:**
Перейдите на: `http://localhost:3000/admin/login`

**Данные для входа:**
- Логин: `1`
- Пароль: `1`

## 📋 Что можно делать в админке

### 1️⃣ Основная страница
- Изменить видео/фото в Hero блоке
- Редактировать все тексты
- Изменить фото в 3 панелях
- Управлять категориями

### 2️⃣ О нас
- Главное фото и весь текст
- Философия компании
- Ценности с иконками

### 3️⃣ Документы
- Загрузить PDF с компьютера
- Указать название и дату
- Удалить документы

### 4️⃣ Аукционы (самый важный раздел)

**Категории:**
- Создать новые категории (Живопись, Часы, Автомобили и т.д.)
- Загрузить фото для каждой категории
- Эти категории появятся в фильтре на странице поиска

**Фильтры:**
- Добавить подкатегории к каждой категории
- Например, для "Живопись": Импрессионизм, Модернизм, и т.д.
- Используются для фильтрации лотов

**Лоты:**
- Добавить новый лот с фото
- Указать категорию и фильтры
- Цена, даты аукциона
- Загрузить сертификат подлинности
- ⭐ **Чекбокс "На главной"** - максимум 4 лота появятся на главной странице

### 5️⃣ Обратная связь
- Просмотр всех заявок от клиентов
- Автоматически удаляются через 24 часа
- Видно время до удаления

## ⚡ Важно

1. **Featured лоты**: Только 4 лота могут быть на главной одновременно

2. **Файлы**: Все загружаются в `/public/uploads/`

3. **Автосохранение**: В каждом разделе есть кнопка "Сохранить все"

4. **Текущий контент**: При первом входе отображается текущий контент сайта, так что вы видите что уже есть в БД

## 🔧 Структура URL

- Админка: `/admin`
- Логин: `/admin/login`
- Основная страница: `/admin/edit/homepage`
- О нас: `/admin/edit/about`
- Документы: `/admin/edit/documents`
- Аукционы: `/admin/edit/auctions`
- Обратная связь: `/admin/contact-requests`

## 💡 Советы

1. Сначала создайте категории
2. Добавьте к ним фильтры
3. Затем создавайте лоты и привязывайте к категориям
4. Отметьте 4 лучших лота для главной страницы
5. Регулярно проверяйте обратную связь

## 📝 Примечание

Все изменения сохраняются в базе данных PostgreSQL и сразу отображаются на сайте.
