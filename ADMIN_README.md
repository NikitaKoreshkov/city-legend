# Админ Панель Hwang's

## Вход в админку

URL: `/admin/login`
- Логин: `1`
- Пароль: `1`

## Инициализация базы данных

Перед первым использованием необходимо инициализировать базу данных. Это создаст все необходимые таблицы и добавит администратора по умолчанию.

Просто перейдите по адресу: `/api/init-db`

Или выполните любой запрос к API - база данных инициализируется автоматически.

## Структура админ панели

### 1. Редактировать сайт

#### 1.1 Основная страница (`/admin/edit/homepage`)
- **Hero блок**: видео/фото, 3 строки текста
- **Описание**: текстовый блок
- **3 панели**: фото и текст для каждой панели
- **Категории**: управление категориями на главной
- **Блок с фото**: малое и большое фото + текст
- **Коллекция Императорского Двора**: заголовок, текст, фото

#### 1.2 О нас (`/admin/edit/about`)
- **Hero секция**: главное фото и весь текст
- **Наша философия**: заголовок, цитата, автор
- **Наши ценности**: фото, заголовок, подзаголовок, список ценностей (иконка, название, описание)

#### 1.3 Документы (`/admin/edit/documents`)
- Добавление PDF файлов с компьютера
- Указание названия и даты документа
- Удаление документов
- Автоматическое отображение на странице `/documents`

#### 1.4 Аукционы (`/admin/edit/auctions`)

**Управление категориями:**
- Добавление/редактирование/удаление категорий
- Загрузка фото для категорий
- Указание порядка сортировки
- Slug для URL

**Управление фильтрами (подкатегориями):**
- Добавление фильтров к каждой категории
- Связь фильтров с категориями
- Используются при поиске и фильтрации лотов

**Управление лотами:**
- Добавление/редактирование/удаление лотов
- Загрузка нескольких фотографий
- Привязка к категории и фильтрам
- Указание цены, дат аукциона
- Загрузка сертификата подлинности (PDF)
- **Чекбокс "Показывать на главной"**: максимум 4 лота могут быть отмечены для отображения на главной странице

### 2. Обратная связь (`/admin/contact-requests`)

- Просмотр всех заявок от клиентов
- Отображение имени, email, телефона, сообщения
- Информация о лоте, если заявка связана с конкретным аукционом
- **Автоматическое удаление через 24 часа**
- Таймер показывает оставшееся время до удаления
- Ручное удаление заявки

## API Endpoints

### Авторизация
- `POST /api/admin/login` - вход в админку
- `POST /api/admin/logout` - выход из админки
- `GET /api/admin/check-auth` - проверка авторизации

### Контент главной страницы
- `GET /api/admin/homepage` - получить весь контент
- `POST /api/admin/homepage` - обновить секцию контента

### Контент страницы О нас
- `GET /api/admin/about` - получить весь контент
- `POST /api/admin/about` - обновить секцию контента

### Документы
- `GET /api/admin/documents` - получить все документы
- `POST /api/admin/documents` - добавить документ
- `DELETE /api/admin/documents?id={id}` - удалить документ

### Категории аукционов
- `GET /api/admin/categories` - получить все категории с подкатегориями
- `POST /api/admin/categories` - добавить категорию
- `PUT /api/admin/categories` - обновить категорию
- `DELETE /api/admin/categories?id={id}` - удалить категорию

### Подкатегории (фильтры)
- `POST /api/admin/subcategories` - добавить подкатегорию
- `PUT /api/admin/subcategories` - обновить подкатегорию
- `DELETE /api/admin/subcategories?id={id}` - удалить подкатегорию

### Лоты (аукционы)
- `GET /api/admin/auctions` - получить все аукционы
- `POST /api/admin/auctions` - добавить аукцион
- `PUT /api/admin/auctions` - обновить аукцион
- `DELETE /api/admin/auctions?id={id}` - удалить аукцион

### Обратная связь
- `GET /api/admin/contact-requests` - получить все заявки (автоматически удаляет старше 24 часов)
- `DELETE /api/admin/contact-requests?id={id}` - удалить заявку вручную
- `POST /api/contact` - создать новую заявку (публичный endpoint)

### Загрузка файлов
- `POST /api/admin/upload` - загрузить файл (изображение, видео, PDF)

## Структура базы данных

### Таблицы:

1. **admin_users** - администраторы
2. **homepage_content** - контент главной страницы (JSONB)
3. **about_content** - контент страницы О нас (JSONB)
4. **documents** - документы (PDF)
5. **auction_categories** - категории аукционов
6. **auction_subcategories** - подкатегории/фильтры
7. **auctions** - лоты аукционов
   - `is_featured` - флаг для отображения на главной (макс 4)
   - `category_id` - связь с категорией
   - `subcategory_ids` - массив ID фильтров
8. **contact_requests** - заявки обратной связи
9. **newsletter_subscriptions** - подписчики рассылки

## Важные особенности

1. **Featured лоты**: Максимум 4 лота могут быть отмечены для главной страницы. При попытке добавить 5-й, система выдаст ошибку.

2. **Автоматическое удаление заявок**: Заявки обратной связи автоматически удаляются через 24 часа после создания.

3. **Загрузка файлов**: Все файлы загружаются в `/public/uploads/` с подкатегориями:
   - `/uploads/images/` - изображения
   - `/uploads/videos/` - видео
   - `/uploads/documents/` - PDF документы

4. **Slug генерация**: Для категорий и подкатегорий используются slug'и для формирования URL. Убедитесь, что они уникальны и используют латиницу.

5. **Связь данных**: При удалении категории, все связанные лоты останутся, но потеряют привязку к категории. Подкатегории удаляются автоматически (CASCADE).

## Безопасность

⚠️ **ВАЖНО**: Текущая реализация использует простую cookie-based аутентификацию без хеширования паролей. Это сделано для простоты, как было запрошено (логин и пароль = "1").

Для production среды рекомендуется:
- Использовать NextAuth.js или аналогичное решение
- Хешировать пароли (bcrypt)
- Добавить CSRF защиту
- Использовать JWT токены
- Добавить rate limiting
- Включить HTTPS

## Техническая информация

- Framework: Next.js 14+ (App Router)
- База данных: PostgreSQL
- ORM: pg (node-postgres)
- Аутентификация: Cookie-based (простая реализация)
- Загрузка файлов: File System API

## Поддержка

При возникновении проблем проверьте:
1. Подключение к базе данных (переменная окружения DATABASE_URL)
2. Инициализацию базы данных (перейдите на `/api/init-db`)
3. Консоль браузера и логи сервера для ошибок
